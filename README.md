# Organic Oil EU website concept

A Next.js website concept for mint oils and menthol materials. The visible logo reads Organic Oil EU; company and product content remains a B.D. Aromatics prototype pending review.

## Run locally

```bash
npm install
npm run dev
```

The product photography is illustrative concept imagery. Product grades, specifications, certification scope and claims require confirmation. The enquiry form opens an editable email draft; it does not store or send data from the website. Search indexing remains disabled while the content is under review.
